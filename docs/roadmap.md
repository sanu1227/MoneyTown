## 다음 검증

| 우선순위 | 작업 | 확인 기준 |
| --- | --- | --- |
| 1 | 기기별 음악·효과음 청취 | 휴대폰 스피커·이어폰에서 음악의 반복감, 효과음과의 음량 균형·구분 확인. 0.24.0 Windows의 직접 선곡·4곡 재생·셔플·곡 전환·설정·효과음·모션 검사는 완료 |
| 1 | 실제 Android 기기 플레이 | 노치·안전 영역, 작은 화면 터치, 수량 키보드·화면 전환·스토리 일러스트와 연출 |
| 2 | 모바일 생명주기와 저장 | 백그라운드·종료·복귀, 결산 대기, 알바 도중 복귀 |
| 3 | 장기 플레이 밸런스 | 새 가격대에서 고가 종목까지 모이는 시간, 상승 확대의 성장 속도, 유료 정보 비용 대비 결과와 구매 빈도 |
| 4 | 처음 플레이하는 사람의 동선 | 종목 선택·+10주 수량 조절·정보 구매·결산·알바를 쉽게 찾는지 |

Windows의 자동 UI 검사는 실제 Android 기기 검증을 대신하지 않습니다. 새 가격대의 장기 플레이 체감과 정보비를 포함한 실제 플레이 밸런스는 아직 미검증입니다. 사건 방향 일치율, 조건부 가격 반응 검사와 유료 정보 구매 후 순수익은 별도로 평가합니다.
