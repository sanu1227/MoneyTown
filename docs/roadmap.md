기준: **2026-10-16 / v0.18.3**. 완료한 기능과 앞으로 검증하거나 검토할 항목을 구분합니다. 아래 순서는 개발 우선순위이며 출시 일정 약속은 아닙니다.

## 구현 완료

- [x] 12개 가상 기업, 차트, 보유 주식과 수수료 포함 주문
- [x] 직접 수량 입력·+10주 누적 증가·최대 매수·보유 수량 선택
- [x] 7가지 자동 갱신 간격과 남은 시간 표시
- [x] 다음 날 결산, 원인과 결과를 보여 주는 개장 뉴스
- [x] 1~10등급의 정보 상품 3,000개와 매체별 지면
- [x] 무작위 봉인 정보·기업 지정 분석·내 보관함·후속 보도
- [x] 3일 정기 예금과 하루를 소모하는 50,000원 물류센터 알바
- [x] 분리된 연습 자금의 튜토리얼, 거래·결산 기록, 목표
- [x] 자동 저장·백업 복구, Windows 설치·업데이트
- [x] Android ARM64 APK 빌드와 공개 Git 저장소

## 다음 검증

| 우선순위 | 작업 | 확인 기준 |
| --- | --- | --- |
| 1 | 실제 Android 기기 플레이 | 노치·안전 영역, 작은 화면 터치, 수량 키보드와 화면 전환 |
| 2 | 모바일 생명주기와 저장 | 백그라운드·종료·복귀, 결산 대기, 알바 도중 복귀 |
| 3 | 장기 플레이 밸런스 | 유료 정보 비용 대비 결과, 등급별 구매 빈도, 성장 속도 |
| 4 | 처음 플레이하는 사람의 동선 | 종목 선택·+10주 수량 조절·정보 구매·결산·알바를 쉽게 찾는지 |

Windows의 자동 UI 검사는 통과했지만 실제 Android 기기 검증을 대신하지 않습니다. 사건 방향 일치율과 유료 정보 구매 후 순수익도 별도로 평가합니다.
