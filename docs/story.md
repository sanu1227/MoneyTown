# MoneyTown 성장 이야기

0.25.0의 이야기는 가상의 투자자가 작은 방에서 출발해 더 넓은 세상을 바라보는 과정입니다. 첫 문장은 사용자가 요청한 **“이건 내가 세계 최고의 부자가 되는 이야기이다”**를 그대로 사용합니다. 주인공의 이름과 성별은 대사에서 정하지 않습니다.

## 장 구성

| 장 | 해금 기준 | 제목 | 핵심 장면 |
| --- | --- | --- | --- |
| 프롤로그 | 게임 시작 | 아직 작은 시작 | 백만 원과 낡은 책상, 창밖의 도시 |
| 1 | 총자산 200만원 | 두 배가 된 가능성 | 옥상에서 돌아보는 첫 성취와 판단의 기록 |
| 2 | 총자산 1천만원 | 나만의 작은 사무실 | 정보를 읽고 자기 기준을 만드는 책상 |
| 3 | 총자산 1억원 | 숫자 너머의 도시 | 차트 뒤에서 살아가는 사람들과 기업 |
| 4 | 총자산 10억원 | 혼자보다 넓은 시야 | 다른 의견을 듣고 책임 있게 결정하는 회의실 |
| 5 | 총자산 100억원 | 더 넓은 세상으로 | 세계 최고의 부자를 향한 다음 장 |

각 장은 세 페이지입니다. 100억원 장은 세계 최고의 부자가 되었다는 결말이 아니라 다음 목표로 이어지는 열린 장면입니다. 별도 자금 보상이나 가격 효과는 없습니다. 전체 대사는 [StoryChapters.cs](../unity/Assets/Scripts/StoryChapters.cs)에 보관합니다.

## 표시와 조작

- 새 게임은 도입부를 먼저 보여 주고, 이후 기존 튜토리얼 또는 게임 화면으로 이어집니다.
- 총자산은 기존 게임과 동일하게 현금·주식 평가액·만기 전 예금 원금을 합산합니다.
- 한 번 해금한 장은 자산이 줄어도 남습니다. 여러 구간을 한 번에 넘으면 순서대로 보여 줍니다.
- 결산과 물류센터 애니메이션이 먼저 끝나며, 성장 이야기는 튜토리얼·설정·도움말과 겹쳐 자동 표시하지 않습니다.
- ‘다음’으로 넘기고 ‘이번 장 건너뛰기’로 해당 장 전체를 확인 처리합니다. 마지막 페이지 또는 건너뛰기에서 저장에 성공한 뒤 닫힙니다.
- 읽는 도중 종료하면 미확인 장의 처음부터 다시 시작합니다. 페이지 단위 진행은 저장하지 않습니다.
- **도움말 > 나의 이야기**에서 해금한 장을 다시 볼 수 있습니다. 다시 보기는 확인 진도나 게임 저장을 바꾸지 않습니다.
- 이야기 중 시세·거래·날짜 진행은 멈추고 기존 배경음악은 계속됩니다.

## 일러스트와 움직임

장마다 별도의 세로 일러스트를 사용합니다. 작은 방·옥상·작업실·도시·회의실·넓은 지평선으로 공간을 확장합니다. 글자는 그림에 구워 넣지 않고 Unity의 한국어 텍스트로 표시합니다. [일러스트 원본·제작 프롬프트](story-art.md)

그림은 천천히 확대·이동하고 페이지 본문은 약 0.3초 동안 나타납니다. 배경으로 나가면 움직임이 멈추며 ‘동작 줄이기’에서는 정지 그림과 즉시 표시한 본문을 사용합니다. 문장을 기다리게 하는 타자 효과는 사용하지 않습니다.

### 0.26.1 신경망 내레이션

첫 문장의 목소리를 무료 로컬 **Supertonic 3 · M2** 남성 프리셋으로 교체했습니다. 문장 전체를 속도 0.9·12단계로 합성하고, 쉼표로 짧은 호흡을 둡니다. 원본부터 44.1kHz이며 차임 음량을 낮춰 말소리를 중심으로 구성했습니다. 게임에서는 완성 WAV를 재생하므로 모델 설치나 인터넷 연결이 필요하지 않습니다. 도움말에 AI 생성 음성임을 표시합니다. [현재 음원과 제작 과정](opening-audio.md)

완성 음원은 약 5.21초입니다. 문구는 0.2·1.3·2.9초부터 각각 0.7초 동안 나타나고, 3~5.25초에 도시를 드러냅니다. 재감상·중단 후 복귀·음량·배경음악 낮추기 동작은 유지합니다. 선정본은 로컬 음성 인식에서 원문과 일치했으며, 실제 청취로 자연스러움과 억양을 평가한 결과는 아닙니다.

### 0.26.0 첫 문장 내레이션 — 이전 기록

첫 문장을 정확히 읽는 한국어 목소리에 낮은 울림·차임·상승 효과음을 더합니다. 유료 생성 서비스 없이 Windows의 `Microsoft Heami Desktop` 한국어 음성과 직접 합성한 소리를 사용합니다. Unity 시작 화면이 끝난 뒤 프롤로그 첫 페이지에서 한 번 재생하며, 음성이 나오는 동안 배경음악은 잠시 작아졌다가 돌아옵니다. [음원과 제작 과정](opening-audio.md)

음원 길이는 약 5.73초입니다. 문구는 음성에 맞춰 0.2·1.11·2.880375초부터 0.7초 동안 나타나고, 3~5.75초에 도시를 드러냅니다. 아래 0.25.1 기록의 연출에 이 타이밍을 적용합니다.

‘문장 바로 보기’는 화면만 즉시 완성하고 음성은 계속합니다. 다음 대사로 넘어가거나 장을 닫으면 중지하며, 프롤로그 재감상은 처음부터 들려줍니다. 앱 중단 때는 멈춘 위치를 보존합니다. 효과음 켜기/끄기·음량 설정을 공유하며, 동작 줄이기는 음성에 영향을 주지 않습니다. 기존 대사·이야기 진도·자산·저장 규칙은 유지합니다.

### 0.25.1 첫 문장 연출

프롤로그의 첫 페이지만 영화의 시작처럼 표시합니다. 화면 중앙에 ‘이건 내가’·‘세계 최고의 부자가’·‘되는 이야기이다’를 세 줄로 배치하고 가운데 줄을 큰 금빛 글씨로 강조합니다. 세 줄은 차례로 나타나고, 어둠이 걷히며 뒤의 도시가 드러납니다.

연출 중 ‘문장 바로 보기’를 누르면 완성된 장면을 즉시 표시하고, 이어 ‘이야기 시작’을 누르면 기존 두 번째 페이지로 넘어갑니다. ‘이번 장 건너뛰기’는 언제든 사용할 수 있습니다. 다시 보기에도 같은 연출을 적용하며 앱 중단 때 시간은 멈춥니다. ‘동작 줄이기’에서는 완성된 정지 장면을 바로 보여 줍니다. 나머지 페이지와 이야기 진도·자산·저장 규칙은 그대로 유지합니다.

## 저장과 기존 진행

게임 저장 형식 12에 해금한 장 수와 확인한 장 수를 추가합니다. 기존 1~11 저장은 도입부 미확인 상태로 읽고 현재 총자산으로 추가 해금을 계산합니다. 과거 최고자산은 추정하지 않습니다. 기존 가격 이전 조건과 자산·거래·정보 기록을 보존합니다. 새 게임은 이야기 진도도 초기화하고 백업 복구는 해당 저장의 진도를 따릅니다.

구현과 실제 검증·배포 결과는 [개발 노트](development-log.md)의 각 버전 항목을 기준으로 확인합니다. Android 실기기의 터치·안전 영역·청취 검증은 Windows Player 검사와 구분합니다.
