# 이전 도입부 음원 보관 안내

**0.27.0부터 내레이션을 제거했습니다.** 현재 이야기는 캡션과 말풍선으로 읽는 두 컷 만화입니다. 내레이션 재생 코드·완성 WAV·원본 음성·제작 메타·전용 생성 스크립트는 현재 배포와 작업 트리에서 제외했습니다. 기존 배경음악과 일반 효과음은 유지합니다.

0.26.1의 Supertonic 3 음성 제작 방법, 원문·구간 시점·SHA-256·라이선스·검증 범위는 [v0.26.1 음원 제작 문서](https://github.com/sanu1227/MoneyTown/blob/v0.26.1/docs/opening-audio.md)에 보존합니다. 당시 파일과 도구를 확인하려면 [v0.26.1 소스](https://github.com/sanu1227/MoneyTown/tree/v0.26.1)를 사용하세요. 이전 버전의 음성 생성·검사 명령은 현재 버전의 개발 절차가 아닙니다.

현재 화면과 조작은 [스토리 문서](story.md), 변경·검증 기록은 [개발 노트](development-log.md), 계속 사용하는 소리는 [배경음악 자료](music-assets.md)와 [효과음 자료](audio-assets.md)에서 확인합니다.
