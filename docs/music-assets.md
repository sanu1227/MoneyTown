# 배경음악 원본과 재현

## After the Bell / 장 마감의 여유

MoneyTown의 차트 확인과 정보 읽기에 맞춰 새로 작곡한 라운지풍 연주곡입니다. 짧은 효과음이 잘 들리도록 멜로디와 타악기를 절제하고, 따뜻한 전자 건반과 부드러운 베이스를 중심으로 구성했습니다. 보컬은 없습니다.

- 템포·박자: 88 BPM, 4/4박자
- 형식: 32마디, A / A′ / B / A″ 각 8마디
- 길이: 87.272721초, 정확히 3,848,727 PCM 프레임
- 원본: 스테레오 44,100 Hz, 16bit PCM WAV
- 크기: 15,394,952바이트, 약 14.68 MiB
- [원본 음원 듣기·받기](../unity/Assets/Resources/Audio/town-lounge.wav)
- [작곡·합성 소스](../scripts/generate-bgm.py)

| 악기 | 역할과 소리 |
| --- | --- |
| 전자 건반 | Rhodes풍의 부드러운 타인 어택, 시간에 따라 약해지는 배음, 네 음으로 쌓은 화음 |
| 베이스 | 저음 기본음·5도·옥타브를 중심으로 진행하며 일부 마디에서 다음 화음으로 접근 |
| 리드 | 가벼운 전자 건반 음색으로 짧은 질문과 응답 프레이즈 연주 |
| 드럼 | 작은 킥, 림, 브러시와 하이햇. 엇박을 조금 늦춘 스윙 리듬 |
| 공간감 | 좌우로 배치한 건반과 작은 타악기, 고음을 줄인 짧은 반사음 |

## 악보와 편곡

A의 화음은 `Dmaj9 – Bm9 – Em9 – A13 – F#m9 – B13 – Em9 – A13`입니다. B에서는 `Gmaj9 – Dmaj9/F# – Em9 – A13 – Dmaj9 – Bm9 – Em9 – A13`으로 바뀝니다. 화음과 각 음의 길이·음높이는 생성기의 `A`, `B`, `MELODY_A`, `MELODY_B`에 직접 작성했습니다.

첫 8마디는 건반과 멜로디 사이에 여유를 둡니다. 두 번째 8마디에는 짧은 반주와 낮은 음역의 응답을 추가합니다. 세 번째 8마디는 화음과 멜로디를 바꾸고 리듬을 조금 확장합니다. 마지막 8마디는 첫 분위기로 돌아오되 높은 건반 응답을 넣고 끝부분의 리드를 비워, 처음으로 자연스럽게 연결합니다. 같은 8마디 오디오를 네 번 복사한 파일이 아닙니다.

## 반복 재생 방식

마지막 음의 감쇠와 공간 반사를 파일 첫 부분에 순환 합산합니다. 마지막에 긴 페이드나 무음을 붙이지 않습니다. 음표와 드럼의 시작·끝에는 짧은 음량 변화를 적용해 클릭을 줄입니다. 전체 32마디를 샘플 단위로 반올림하므로 이론적인 길이와 실제 길이는 한 프레임 이내로 일치합니다.

Unity importer는 PCM, 스테레오, 정규화 끄기, **Streaming(loadType 2)**를 사용합니다. 긴 곡의 전체 디코딩 버퍼를 상주시킬 필요를 줄이고 원본 루프 길이를 보존합니다. 런타임은 이 원본 한 파일을 반복 재생합니다. 별도 미리듣기 복사본은 없습니다.

## 생성·검증

외부 도구나 음악 라이브러리 설치 없이 Python 표준 라이브러리만 사용합니다.

```powershell
python scripts/generate-bgm.py
python scripts/generate-bgm.py --check
```

첫 명령은 WAV와 `.meta`를 생성합니다. `--check`는 파일을 수정하지 않고 같은 악보에서 다시 합성해 바이트 일치, 메타데이터, PCM 형식, 길이, 최대 진폭, RMS, 반복 경계와 무음 구간을 검사합니다. 난수는 드럼 음색에만 고정 시드로 사용하며 게임 난수와 무관합니다.

2026-10-16 생성 결과:

| --- | --- |
| 최대 진폭 | 0.500000 (약 −6.02 dBFS) |
| 전체 RMS | 0.100205 (약 −19.98 dBFS) |
| 반복 경계의 인접 샘플 차이 | 0.001251 |

위 수치는 PCM 원본 분석 결과입니다. 실제 스피커·이어폰의 청취 품질을 확인했다는 의미는 아닙니다. 플랫폼별 실제 재생·배경 전환 검증은 개발 노트의 해당 배포 기록을 확인합니다.

## 출처와 권리

이 프로젝트를 위해 음표, 리듬과 합성 파형을 직접 작성했습니다. 다른 게임·상업 음원·외부 샘플·사운드폰트·음악 생성 서비스의 출력물은 사용하지 않았습니다. 기존 곡의 멜로디를 옮기지 않았으며, 프로젝트에서 원본 음원과 생성 소스를 함께 관리합니다. 별도의 제3자 샘플 표기나 이용료가 필요한 자산은 포함하지 않았습니다.
