# 배경음악 원본과 재현

MoneyTown의 차트 확인과 정보 읽기에 맞춰 직접 작곡한 연주곡 4곡입니다. 같은 곡만 이어서 듣는 지루함을 줄이도록 템포·화성·악기·리듬을 나눴습니다. 보컬과 외부 샘플은 없습니다. 총 원본 길이는 **299.272721초, 약 4분 59초**입니다.

## 악보와 편곡

### 장 마감의 여유

4/4박자 32마디, A / A′ / B / A″ 각 8마디입니다. A의 화음은 `Dmaj9 – Bm9 – Em9 – A13 – F#m9 – B13 – Em9 – A13`입니다. B에서는 `Gmaj9 – Dmaj9/F# – Em9 – A13 – Dmaj9 – Bm9 – Em9 – A13`으로 바뀝니다.

첫 부분은 전자 건반과 멜로디 사이에 여유를 두고, 다음 부분에는 낮은 음역의 응답을 넣습니다. B에서는 음역과 리듬을 확장하고 마지막에는 높은 건반 응답을 더합니다. 기존 0.22.0 원본과 Unity 메타는 바이트 그대로 보존했습니다.

### 아침의 티커

4/4박자 24마디, A / B / A′ 각 8마디입니다. C 장조 중심의 `Cmaj9 – Am9 – Dm9 – G13` 진행에서 시작합니다. 중간에는 Fmaj9으로 영역을 넓히고 첫 화성으로 돌아옵니다.

마림바의 짧은 기본음과 빠르게 줄어드는 높은 배음이 건반 화음 사이를 채웁니다. 멜로디는 짧게 도약하고 응답하며, 펠트 건반과 기본음·5도 베이스가 직선적인 리듬을 유지합니다. 마지막 A′는 일부 멜로디를 낮은 옥타브로 바꾸고 마지막 응답을 비웁니다.

### 신문 가판대

4/4박자 24마디, A / B / A′ 각 8마디입니다. `G6/9 – F#m7♭5 – B7 – Em9 – Am9 – D13 – Gmaj9 – D13`을 중심으로, B에서는 Cmaj9과 C#m7♭5를 거쳐 돌아옵니다.

줄을 순서대로 튕기는 느낌의 화음을 짧게 엇박에 배치하고, 베이스는 강박과 짧은 5도 응답을 연주합니다. 합성한 나일론 플럭은 낮은 배음을 오래 남기고 높은 배음을 빠르게 줄입니다. 림과 브러시는 부드러운 보사노바 리듬을 받칩니다. 멜로디는 아침곡보다 낮고 길게 연결됩니다.

### 도시의 야간장

4/4박자 24마디, A / B / A′ 각 8마디입니다. `Ebmaj9 – Cm9 – Abmaj9 – Bb13 – Gm9 – Cm9 – Fm9 – Bb13`과, Abmaj9에서 시작하는 중간 부분으로 구성했습니다.

패드는 천천히 시작해 화음의 공간을 유지합니다. 벨은 한 마디에 한두 음만 연주하고, 베이스는 길게 지속합니다. 킥과 브러시도 최소한으로 배치했습니다. A′에는 높은 벨 응답을 작게 더합니다. 지속음 때문에 평균 음량이 높아지지 않도록 다른 곡보다 최대 진폭을 낮췄습니다.

모든 곡은 각 부분을 음표 단위로 합성합니다. 짧은 오디오 조각을 복사하거나 기존 곡을 속도만 바꾼 파일이 아닙니다.

## 원본과 재생

공통 형식은 **스테레오 44,100 Hz, 16bit PCM WAV**입니다. Unity importer는 PCM, 스테레오, 정규화 끄기, **Streaming(loadType 2)**를 사용합니다. 긴 곡의 전체 디코딩 버퍼를 상주시킬 필요를 줄이고 정확한 길이를 보존합니다.

음의 감쇠와 짧은 좌우 반사음을 파일 첫 부분에 순환 합산했습니다. 파일 끝에 긴 페이드나 무음은 없습니다. 음표·타악기의 시작과 끝에는 짧은 음량 변화를 적용합니다. 원본 자체의 반복 경계를 검사하므로 파일의 처음과 끝에서도 클릭을 줄입니다.

0.23.0에서는 원본 4곡을 무작위 순서로 재생합니다. 같은 곡이 연속으로 나오지 않으며 곡 전환의 짧은 페이드는 런타임에서 처리합니다. 곡 선택은 시장 시뮬레이션 난수와 독립적입니다. 음악 설정과 앱 중단·복귀 동작의 실제 Player 검증은 개발 노트의 배포 기록을 확인합니다.

## 생성·검증

외부 도구나 음악 라이브러리 설치 없이 Python 표준 라이브러리만 사용합니다.

```powershell
python scripts/generate-bgm.py
python scripts/generate-bgm.py --check
```

첫 명령은 4곡과 `.meta`를 생성합니다. 이미 같은 바이트인 파일은 다시 쓰지 않습니다. `--check`는 파일을 수정하지 않고 같은 악보에서 다시 합성해 WAV·메타 바이트 일치, 서로 다른 SHA-256, PCM 형식, 정확한 길이, 최대 진폭, RMS, 반복 경계와 무음 구간을 검사합니다. 기존 라운지 원본 SHA-256은 고정값과 추가로 대조합니다. 드럼의 난수는 고정 시드로 사용하며 게임 난수와 무관합니다.

## 출처와 권리

이 프로젝트를 위해 음표, 리듬과 합성 파형을 직접 작성했습니다. 다른 게임·상업 음원·외부 샘플·사운드폰트·음악 생성 서비스의 출력물은 사용하지 않았습니다. 기존 곡의 멜로디를 옮기지 않았으며, 프로젝트에서 원본 음원과 생성 소스를 함께 관리합니다. 별도의 제3자 샘플 표기나 이용료가 필요한 자산은 포함하지 않았습니다.
