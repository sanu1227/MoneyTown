# MoneyTown 개발 노트

이 문서는 앞으로 개발할 작업과 실제 수행 결과를 기록합니다. 날짜는 Asia/Seoul 기준이며 작업별로 목표, 변경, 결정, 검증과 남은 작업을 추가합니다. 완료와 계획을 구분하고 과거 기록을 보존합니다.

## 현재 개발 단계

Unity Android 0.9에서 별도 연습 자금으로 진행하는 10단계 튜토리얼과 다시 열 수 있는 도움말을 제공합니다. 1~10등급 정보 1,000개와 기업 지정 분석도 유지합니다. `unity/`가 주 개발 대상이며 기존 Kotlin 앱과 웹 프로토타입은 거래 규칙 비교 자료로 유지합니다. 최신 검증 상태는 아래 0.9 기록을 확인합니다. 실제 휴대폰과 장기 밸런스 검증은 아직 진행하지 않았습니다.

### 결정과 이유

문서는 개발 중 갱신하기 쉬운 로컬 Markdown으로 작성했습니다. 모바일 엔진을 확정하기 전에 HTML/CSS/JavaScript로 거래의 핵심을 확인합니다. 외부 패키지 없이 실행하고 Node 기본 테스트를 사용합니다.

첫 버전의 시간은 ‘다음 날’ 버튼으로 진행합니다. 자동 시세 갱신은 뉴스와 거래의 원인·결과를 확인한 뒤 추가합니다. 금액은 정수로 계산하고 수수료는 올림 처리합니다. 부분 매도 원가는 BigInt 나눗셈으로 계산해 큰 정수의 곱셈 오차를 피합니다.

저장 읽기에 실패하면 기존 데이터를 보존하고 거래를 막습니다. 저장 쓰기에 실패하면 저장되지 않았음을 안내합니다. 초기화는 플레이어가 확인한 뒤 수행합니다. 여러 탭의 동시 플레이는 현재 지원하지 않습니다.

### 한계와 남은 검증

실제 Android/iOS 실행, 다른 브라우저, 360px 화면, 저장 공간 부족·차단의 UI, 다중 탭 충돌, 접근성 보조기기와 장기 경제 밸런스는 아직 검증하지 않았습니다. 현재 뉴스는 기업 사건 한 종류이며 업종·시장·소문 뉴스는 기획 단계입니다. 목표 보상, 손실 복구, 거래 내역과 사업·부동산도 아직 구현하지 않았습니다.

프로토타입의 예금 수익과 가격 제한은 게임용 잠정값입니다. 첫 화면 미리보기에는 테스트 중 만든 거래 상태가 표시됩니다. 게임 데이터는 브라우저 저장 공간에 있으며 소스 파일에는 저장하지 않습니다.

## 2026-10-09 Android 네이티브 앱 전환

### 목표

사용자가 웹사이트 대신 앱으로 개발하고 Android부터 진행하기를 선택했습니다. 기존 핵심 기능을 독립 실행 가능한 APK로 옮깁니다.

### 실제 변경

- `android/`에 Kotlin·Jetpack Compose 프로젝트를 생성했습니다. WebView나 웹 서버를 사용하지 않습니다.
- 6개 기업, 주식 매수·매도, 0.1% 수수료, 부분 매도 원가, 가격 차트, 공개 뉴스, 보고서, 예금과 하루 진행을 이식했습니다.
- 주식, 뉴스·정보, 자산의 네이티브 하단 탭을 추가했습니다.
- 앱 내부 버전 지정 저장과 AtomicFile을 적용했습니다. 저장 실패 시 행동을 반영하지 않으며 손상 저장은 자동 덮어쓰지 않습니다. 새 게임 시작 시 기존 파일을 백업합니다.
- `Build-Android.ps1`에 단위 테스트, 빌드, Lint와 APK 복사를 묶었습니다.
- `dist/MoneyTown-debug.apk`를 생성했습니다. applicationId는 `com.moneytown.game`, 최소 Android 8.0, targetSdk 36, 버전 0.2.0입니다.
- 기획서·README·AGENTS.md를 Android 주 개발 기준으로 변경했습니다.

### 결정과 이유

현재 게임은 거래와 정보 UI가 중심이므로 이미 설치된 Android 개발 환경의 Kotlin과 Jetpack Compose를 선택했습니다. 기존 프로젝트에서 확인한 Gradle 9.1.0, Android Gradle Plugin 9.0.1, Compose BOM 2026.03.01을 사용했습니다. 별도 게임 엔진은 설치하지 않았습니다.

순수 Kotlin의 불변 상태를 사용해 거절된 거래가 원래 상태를 바꾸지 않게 했습니다. 기존 웹과 같은 시드 난수 및 금액 범위로 비교합니다. 웹 저장은 앱으로 자동 이전하지 않습니다. 시장은 앱을 닫아도 진행되지 않습니다.

### 검증 결과

- Kotlin 단위 테스트 8개 통과: 매매 원가와 수수료, 잘못된 거래, 보고서 만료, 예금 만기, 저장 왕복, 손상 파일 거절, 시장 재현, 큰 수량과 부분 매도 원가.
- 기존 JavaScript 기준 테스트 6개 통과.
- `Build-Android.ps1` 성공: 테스트, APK 생성과 Lint 완료. Lint 오류 0개, 경고 4개. 경고는 targetSdk·Gradle·Compose 최신 버전 안내와 Android 12 백업 규칙 관련입니다.
- 최초 Lint에서 Android 8.0에 없는 BigInteger API와 테마 속성을 발견해 수정했습니다.
- API 36 에뮬레이터 설치와 실행 성공. 실제 1주 매수 후 현금 989,990원, 다음 날 가격 10,008원 및 총자산 999,998원 확인.
- 보고서 구매 후 987,990원, 예금 가입 후 887,990원과 5일차 만기 표시 확인.
- 업데이트 설치 후 보유 상태 유지 확인. 상태바 대비와 선택된 종목 색상을 실제 화면에서 보정했습니다.
- 앱 강제 종료 후 재실행하여 2일차, 현금 887,990원, 총자산 997,998원과 가격 10,008원 복원을 확인했습니다. `assets/android-trading.png`, `assets/android-assets.png`에 검증 화면을 저장했습니다.

### 한계와 남은 검증

실제 휴대폰, Android 8.0 런타임, 가로 화면·큰 글꼴, 앱 데이터 손상 및 저장 공간 부족의 UI는 아직 검증하지 않았습니다. 저장 코덱의 손상 파일 거절은 단위 테스트로 확인했습니다. 작은 저장 파일은 현재 UI 스레드에서 동기 저장하며 저장 규모가 커지면 직렬화된 백그라운드 저장으로 옮깁니다.

APK는 디버그 서명된 개발용이며 스토어 배포 설정은 아직 없습니다. Lint의 백업 정책 경고에 따라 출시 전 Android 12 이상의 명시적 추출 규칙을 검토해야 합니다. 현재 저장 및 초기화 백업은 앱 내부 파일입니다. 실제 기기 연결은 확인되지 않았고 검증은 에뮬레이터에서 수행했습니다.

### 다음 작업

Android 앱에서 첫 거래 튜토리얼과 거래 내역을 추가합니다. 실제 휴대폰에서 터치, 키보드, 종료·복귀를 검증하고 이후 목표 보상과 업종 뉴스를 구현합니다.

### 한계와 남은 검증

일반 .NET 코어 검증은 Unity의 화면 컴파일 또는 실행 검증을 대신하지 않습니다. Unity 설치·활성화와 에디터 검증의 최종 상태는 후속 기록으로 추가합니다. 이전 `dist/MoneyTown-debug.apk`는 Kotlin 버전이며 Unity APK로 표시하지 않습니다.

## 2026-10-09 Unity 활성화 후 컴파일 및 실행 검증

### 실제 변경

- Unity 6000.3.26f1과 Android Build Support 설치를 완료하고 Hub에 에디터 경로를 등록했습니다.
- Unity 배포 OpenJDK 17.0.18+8과 NDK r27c를 `Tools/UnityToolchains/`에 설치했습니다. 기존 Android SDK와 CMake 3.22.1을 사용합니다.
- 빌드 시 `MONEYTOWN_ANDROID_SDK`, `MONEYTOWN_ANDROID_NDK`, `MONEYTOWN_ANDROID_JDK` 환경변수로 외부 도구 경로를 지정하도록 추가했습니다.

### 결정과 이유

이미 설치된 Android SDK를 재사용하고, Unity가 요구하는 NDK·JDK를 별도로 준비했습니다. Android ARM64 IL2CPP 빌드를 기본으로 유지합니다. 기존 Kotlin APK는 보존합니다.

## 2026-10-09 Unity Android APK 빌드와 에뮬레이터 검증

### 목표

### 실제 변경

- Android 그래픽 API를 OpenGL ES 3로 지정했습니다. 최초 Vulkan 빌드는 API 36 x86_64 에뮬레이터의 ARM64 변환 경로에서 `vulkan.ranchu.so / vk_common_SetDebugUtilsObjectNameEXT` 오류로 종료됐습니다. GLES3로 재빌드한 뒤 정상 실행됐습니다.
- `Build-Unity.ps1 -Target Editor`를 추가해 프로젝트를 직접 열 수 있도록 했습니다. Hub 에디터 등록은 성공했지만 프로젝트 가져오기는 '프로젝트를 찾을 수 없습니다'로 실패해 직접 열기를 사용했습니다.
- README에 로컬 도구 경로, 직접 열기와 배치 빌드 전 에디터 종료 방법을 기록했습니다.

### 검증 결과

- `Build-Unity.ps1 -Target Android`: Unity 6000.3.26f1, IL2CPP, ARM64 개발 빌드 성공.
- 결과: `dist/unity/MoneyTown-Unity.apk`, 42,235,474바이트. 패키지 `com.moneytown.unity`, 버전 0.3.0, 최소 API 26, 대상 API 37, ABI `arm64-v8a`.
- SHA-256: `B8051A830554D4DDB5EA073AC02131159442E03CF73D8A656DCDD675E20899A2`.
- API 36 에뮬레이터에 설치 성공. OpenGL ES 3.1로 한국어 화면, 차트와 3개 탭이 표시됐습니다.

에뮬레이터는 ARM64 코드를 번역 실행하는 x86_64 환경입니다. 실제 ARM64 휴대폰 검증은 수행하지 않았습니다. 에뮬레이터 자동 입력으로 스와이프 스크롤 동작은 확인하지 못했으며, 모바일 수량 키보드·매수·매도와 안전 영역의 실기기 확인이 남았습니다. Windows에서는 스크롤·매수·매도·보고서·예금 만기를 확인했습니다. APK는 개발용 서명이며 스토어 출시용 빌드가 아닙니다.

- 구매 당시 가격 기록·기사 방향·소문·발행일을 저장합니다. 보관함은 종류·기업별 최근 구매본을 보관하며 만료 자료도 열람할 수 있습니다. 만료 후 재구매는 해당 자료를 최신판으로 교체합니다.
- `InformationScreen.cs`: 2×2 상품 가판대, 대상 기업 선택, 보관함과 자료 열람 화면을 추가했습니다. `GameScreen`을 partial로 나눠 기존 거래·자산 화면과 정보 화면을 구분했습니다.
- `PaperSheet.cs`: 신문 용지, 리서치 문서, 그래프 용지, 노란 줄 메모에 종이 결, 접힌 모서리, 찢긴 가장자리, 테이프를 Unity 도형으로 그립니다. 지면에는 제호, 기사 단, 기업 삽화, 분석 게이지, 차트와 미확인 도장을 배치했습니다. 외부 신문·브랜드 이미지는 사용하지 않았습니다.
- `Market.NextChange`를 공유해 찌라시가 실제 다음 가격 방향과 관련된 단서를 제공하되 고정된 오류 마스크로 틀릴 수 있도록 했습니다. 읽기·구매는 실제 시장의 난수나 가격을 바꾸지 않습니다.
- 저장 내부 형식을 버전 2로 확장했습니다. 기존 버전 1의 자산·진행·유효 보고서를 읽고 다음 저장부터 새 형식으로 기록합니다. 파일명과 원자적 저장·백업 방식은 유지했습니다.
