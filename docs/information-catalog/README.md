# 정보 카탈로그 · 3,000개

300개 사건 원안을 10단계 깊이로 집필했습니다. 각 등급에 300개 상품이 있고 각 상품의 긍정/부정 판본을 함께 수록합니다. 10등급이 최고입니다. 이 목록은 집필용으로 기업·사건을 모두 표시하며, 게임의 봉인 구매 화면에는 이를 숨깁니다.

0.14 본문 발행판 3은 사건마다 별도로 쓴 현장 묘사·사업 배경·후속 확인 항목을 반영합니다. 낮은 등급도 구체적인 흔적을 담되 관계자와 맥락은 불확실하게 남깁니다. 높은 등급은 기업·운영 지표·실행 조건·반대 시나리오를 제공합니다. 0.12.1은 설명서처럼 들리던 반복 문구를 줄이고 매체별 문체를 적용해 약 220~1,300자로 정리했습니다. 가격·신뢰도·실제 사건·지표 계산은 기존과 같습니다.

원안은 `content/information-events.psv`, 취재 묘사는 `content/information-dossiers.psv`, 구어체 현장 묘사는 `content/information-conversations.psv`에서 편집합니다. `python scripts/build_information_catalog.py`로 현재 게임 본문과 이 목록을 재생성하고 `python scripts/test_information_catalog.py`로 3,000개 상품·봉인용 6,000개 판본·기업 지정용 1,800개 본문을 검사합니다. 기업 지정용은 6·8·10등급 목록 아래 별도로 수록합니다. 신규 사건은 `content/expansion-a-*.psv`, `content/expansion-b-*.psv`에 각각 100개씩 있습니다. 기존 사건 100개 뒤에 A, B 순서로 추가합니다. 발행판 1·2 구매본은 `unity/Assets/Resources/information-catalog-v1.txt`, `information-catalog-v2.txt`로 동결하며 덮어쓰지 않습니다.
