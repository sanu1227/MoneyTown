# 상승 개장 수익 비교

실제 Unity 코어의 가격 모델 3·4를 같은 초기 시장에서 비교하는 .NET 진단 도구입니다. 게임 저장·설정을 읽거나 쓰지 않습니다. 외부 패키지와 네트워크를 사용하지 않습니다.

```powershell
dotnet run --project tests/investment-growth/InvestmentGrowth.csproj
# 시드 수 변경: 1~10,000
dotnet run --project tests/investment-growth/InvestmentGrowth.csproj -- 2000
```

기본 범위는 **시드 1~128 × 12기업 = 1,536개 조건**입니다. 각 조건마다 100만원으로 해당 기업을 수수료 포함 최대 수량 매수하고, 다음 날 결산을 확인한 뒤 전량 매도합니다. 다른 기업을 보유하지 않은 독립 회차이며 장중 갱신과 정보 구매는 없습니다. 최대 매수·실제 거래·개장·결산 확인은 모두 제품 코드를 호출합니다. 순손익은 왕복 수수료와 남은 현금을 포함한 최종 현금에서 시작 현금을 뺀 값입니다.

**모든 기업에 먼저 투자한 결과를 얻은 다음**, 구형 모델에서 상승·하락·보합이었던 표본을 나누어 평균·최저·최대 순손익과 평균 개장 등락률을 출력합니다. 미래를 알고 종목을 고르는 플레이 전략이 아닙니다. 상승했던 경우 가격 반응과 수수료 차감 수익이 얼마나 달라졌는지 보는 조건부 진단입니다. 정보 판독 능력, 정보비 포함 성과, 장기 성장률이나 수익 보장을 측정하지 않습니다.

비교할 때만 첫날 상태의 `MarketVersion`을 각각 3과 4로 설정합니다. `NextDay` 이후 두 상태 모두 모델 4로 전환되므로 구형 모델을 여러 날 누적한 결과로 해석하면 안 됩니다.

검사는 상승 표본의 가격·순이익 증가, 하락·보합 표본의 가격·순손익·수수료 동일, 개장 방향 유지, 상승 상한 12%, 거래 전후 시장 경로 동일, 날짜·일일/장중 난수·다음 날 사건·정보 상품 동일을 확인합니다. 실패하면 예외와 종료 코드로 알립니다. 표본 집계는 정수 체결 후 실제 가격으로 계산하므로 표시 반올림이 포함됩니다.

2026-10-16 기본 조건 실행 결과는 다음과 같습니다. 1,536개 조건의 검사를 통과했으며 보합 표본은 없었습니다.

| 사후 분류 | 표본 | 평균 개장 등락률: 모델 3 / 4 | 평균 왕복 순손익: 모델 3 / 4 |
| --- | ---: | ---: | ---: |
| 상승 | 770 | +2.56% / +7.52% | +23,323.73원 / +72,471.86원 |
| 하락 | 766 | −2.38% / −2.38% | −25,520.95원 / −25,520.95원 |

상승 표본의 순이익 범위는 모델 3에서 12,725~54,875원, 모델 4에서 42,095~117,762원이었습니다. 정보비를 제외한 조건부 결과이며 실제 플레이의 평균 수익률로 해석하지 않습니다.

별도 [전략 비교](../strategy-comparison/README.md)를 동일한 30일·하루 2틱·12시드로 실행했습니다. 초기 100만원의 12기업 균등 보유 평균 수익률은 기존 +2.59%에서 +103.55%, 무작위 매매는 +1.03%에서 +50.17%로 증가했습니다. 기존 결과는 `24904a3`에서, 새 결과는 0.19.0에서 측정했습니다. 상승 반응 확대는 장기 보유에도 적용되는 강한 성장 조정입니다.

봉인 4·5등급을 매일 사는 제한적 판독 전략은 −97.42%에서 −97.67%로, 초기 정보비 부담이 계속됩니다. 이 전략은 새 실행에서 구매한 기사 약 79.34%를 판독하지 못했으며 사람의 판단 능력을 대신하지 않습니다. 가격 변화만으로 모든 정보 구매가 유리해지는 것으로 해석하지 않습니다. 로컬 실행 로그는 `build/economy-audit-20261016/`에 보관합니다.

상승폭이 커져도 비싼 정보가 항상 이익인 것은 아닙니다. 예를 들어 100만원에서 정보비 75,000원을 먼저 쓰면 남은 돈을 모두 투자해도 왕복 수수료를 포함한 손익분기 상승률은 대략 8.3%입니다. 실제로는 정수 수량으로 남는 현금에 따라 달라지며, 정보 내용이 틀리거나 종목을 잘못 해석하면 손실이 날 수 있습니다. 이 예시는 정보 구매 전략의 측정 결과가 아닙니다.
