# 상승 개장 수익 비교

실제 Unity 코어의 가격 모델 3·4를 같은 초기 시장에서 비교하는 .NET 진단 도구입니다. 게임 저장·설정을 읽거나 쓰지 않습니다. 외부 패키지와 네트워크를 사용하지 않습니다.

```powershell
dotnet run --project tests/investment-growth/InvestmentGrowth.csproj
# 시드 수 변경: 1~10,000
dotnet run --project tests/investment-growth/InvestmentGrowth.csproj -- 2000
```

기본 가격 비교 범위는 **시드 1~128 × 12기업 = 1,536개 조건**입니다. 모든 조건에서 가격 방향·하락 가격·난수·사건을 비교합니다. 100만원으로 수수료를 포함해 1주 이상 살 수 있는 기업만 최대 수량 매수하고, 다음 날 결산을 확인한 뒤 전량 매도합니다. 매수할 수 없는 기업은 가격 비교를 유지하고 거래만 건너뜁니다. 다른 기업을 보유하지 않은 독립 회차이며 장중 갱신과 정보 구매는 없습니다. 최대 매수·실제 거래·개장·결산 확인은 모두 제품 코드를 호출합니다. 순손익은 왕복 수수료와 남은 현금을 포함한 최종 현금에서 시작 현금을 뺀 값입니다.

**매수 가능한 모든 기업에 투자한 결과를 얻은 다음**, 구형 모델에서 상승·하락·보합이었던 거래 표본을 나누어 평균·최저·최대 순손익과 평균 개장 등락률을 출력합니다. 미래를 알고 종목을 고르는 플레이 전략이 아닙니다. 상승했던 경우 가격 반응과 수수료 차감 수익이 얼마나 달라졌는지 보는 조건부 진단입니다. 정보 판독 능력, 정보비 포함 성과, 장기 성장률이나 수익 보장을 측정하지 않습니다.

비교할 때만 첫날 상태의 `MarketVersion`을 각각 3과 4로 설정합니다. `NextDay` 이후 두 상태 모두 모델 4로 전환되므로 구형 모델을 여러 날 누적한 결과로 해석하면 안 됩니다.

검사는 전체 가격 조건에서 상승 가격 증가, 하락·보합 가격 동일, 개장 방향 유지, 상승 상한 12%, 날짜·일일/장중 난수·다음 날 사건·정보 상품 동일을 확인합니다. 모델 간 초기 매수 가능 수량도 같아야 합니다. 실제 거래 조건에서는 상승 순이익 증가, 하락·보합 순손익·수수료 동일, 거래 전후 시장 경로 동일을 추가로 확인합니다. `price_conditions`, `traded_conditions`, `skip_count`를 출력하고 거래 수와 건너뛴 수의 합이 전체 가격 조건 수와 일치하는지 검사합니다. 실패하면 예외와 종료 코드로 알립니다. 표본 집계는 정수 체결 후 실제 가격으로 계산하므로 표시 반올림이 포함됩니다.
