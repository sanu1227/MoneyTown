# 정보 비용과 전략 비교

Unity 게임 코어와 현재·이전 정보 카탈로그를 그대로 참조하는 **오프라인 게임 밸런스 진단 도구**입니다. 외부 패키지·네트워크·게임 저장 파일을 사용하지 않습니다. .NET 빌드 산출물만 이 테스트 폴더의 `bin/`, `obj/`에 생성됩니다.

MoneyTown 루트에서 .NET 10 SDK로 실행합니다.

```powershell
dotnet run --project tests/strategy-comparison/StrategyComparison.csproj
# 60일, 하루 장중 갱신 4회, 개별 시드 결과 포함
dotnet run --project tests/strategy-comparison/StrategyComparison.csproj -- 60 4 --details
```

기본값은 30일·하루 장중 갱신 2회입니다. 12개 고정 시드와 시작 현금 100만·1천만·1억원을 각각 비교합니다. 하루는 같은 횟수의 장중 갱신 → 전략 실행 → 다음 날 개장 → 결산 확인 순서입니다. 모든 전략의 날짜·시세·가격 이력·일일/장중 난수·뉴스 경로가 일치하는지 매 단계 확인하며, 조회와 거래가 입력 상태를 바꾸지 않는지도 검사합니다. 첫 시드·100만원 시나리오를 다시 실행해 결과의 결정성을 확인합니다.

| 전략 | 고정 행동 |
| --- | --- |
| `cash` | 아무 거래도 하지 않고 현금 보유 |
| `equal_weight_hold` | 첫날 여섯 기업에 시작 현금의 1/6씩 수수료 포함 최대 수량을 배정하고 계속 보유 |
| `random_daily` | 매일 전량 매도 후 50% 확률로 임의 기업 하나를 전액 매수; 시장과 분리된 고정 난수 사용 |
| `sealed_grade_4_5` | 매일 전량 매도 후 표지 가격이 가장 낮은 4·5등급 봉인 정보 한 건 구매; 판독된 긍정일 때 관련 기업을 전액 매수 |
| `company_grade_6` | 매일 전량 매도 후 기업을 순서대로 바꿔 6등급 분석 한 건 구매; 판독된 긍정일 때 해당 기업을 전액 매수 |

정보가 없거나 현금이 부족하면 구매하지 않습니다. 지출 한도 비율은 두지 않아 정보 구매가 거래 여력을 얼마나 줄이는지 드러냅니다. 정보 구매 후 판독 실패·부정이면 현금을 보유합니다. 예금·공매도·신용·현금 보상은 사용하지 않으며, 마지막 자산은 청산 수수료를 추가하지 않은 평가액입니다. 따라서 마지막까지 보유한 주식의 미실현손익을 포함합니다.

## 본문만 사용하는 제한적 판독

구매 전 전략에는 상품 번호·등급·가격만 전달합니다. 결제 후에는 화면에 표시되는 제목과 본문만 전달하며, 내부 기업 번호·사건 번호·실제 사건·참/거짓 플래그·미래 가격을 읽지 않습니다. 후속 보도도 다음 매매에 사용하지 않습니다.

4·5등급은 본문에 정확히 한 기업의 업종명(식품·게임·기술·에너지·물류·의료)이 포함될 때만 해당 기업으로 추정합니다. 여러 업종이나 업종명이 없는 내용은 건너뜁니다. 5·6등급은 공개된 ‘사업 여건 개선’ 또는 ‘사업 여건 부담’ 문장을, 나머지는 첫 문단의 소수 긍정·부정 단어를 읽습니다. 경쟁작의 연기처럼 의미가 뒤집히거나 방향이 섞이면 건너뜁니다. 6등급은 공개된 기업명으로 기업을 찾습니다.

이 단순 판독은 사람의 독해 능력을 재현하지 않습니다. 업종 단어가 우연히 등장해 오인할 수 있고, 유용한 기사를 못 읽을 수도 있습니다. 기업 지정 전략과 봉인 전략은 비용뿐 아니라 기업 선택·판독 성공률도 다릅니다. 정보 구매 전략의 성과를 정보 자체의 순수 효과나 최적 전략의 성과로 해석하면 안 됩니다. 수수료·가격·시장 규칙은 수정하지 않았습니다.

## 출력 지표

기본 출력은 시작 자산·전략별 12개 시드의 CSV 요약입니다. `--details`는 시드별 원자료를 JSON 한 줄씩 추가합니다. 실행 시간·현재 날짜·임시 경로를 출력하지 않아 같은 코드·인수의 결과를 비교하기 쉽습니다.

- `mean_final_assets`, `mean_return_pct`, `min_return_pct`, `max_return_pct`: 최종 평가자산과 시작 자산 대비 수익률. 수익 보장이나 실전 투자 모델이 아닙니다.
- `mean_info_cost`, `mean_fees`, `mean_purchases`: 회차당 정보 지출·실제 매매 수수료·구매 건수.
- `mean_buy_blocked_attempts`: 전략이 매수하려 했지만 배정 예산으로 수수료 포함 1주도 살 수 없었던 횟수.
- `cash_blocked_days_pct`: 전략 실행 직후 현금으로 어느 종목 1주도 못 사는 날 / 전체 날. **주식을 많이 보유해 현금이 적은 상태도 포함**하므로 자산 고갈과 다릅니다.
- `depleted_days_pct`, `depleted_runs_pct`: 하루 전략 직후 또는 다음 개장에 주식·예금이 없고 현금으로 어느 종목 1주도 못 사는 상태를 관찰한 날·회차 비율. 영구 파산 판정은 아닙니다.
- `mean_info_initial_pct`: 회차당 전체 정보 지출 / 초기자산 비율의 평균.
- `mean_purchase_cash_pct`: 개별 정보 가격 / 구매 직전 현금 비율의 구매 건수 가중 평균.
- `unread_purchases_pct`: 기업 또는 방향을 판독하지 못한 구매 / 전체 구매 비율. 구매 0건인 지표 비율은 0으로 출력합니다.
- `mean_info_unaffordable_days`, `mean_no_offer_days`: 사려는 자료의 현금 부족 또는 당일 4·5등급 부재로 구매하지 못한 날의 회차 평균.

가격·수수료·정보 신뢰도 조정 전에 여러 기간·장중 갱신 횟수와 실제 플레이 관찰을 함께 비교하세요. 고정된 소수 시드·단순 전액 매매·매일 정보 구매로 나온 결과만으로 가격을 자동 조정하지 않습니다.
