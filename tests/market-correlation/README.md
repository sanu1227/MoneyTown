# 정보와 개장 반응 검증

프로젝트 루트에서 실행합니다.

```powershell
dotnet run --project tests/market-correlation/MarketCorrelation.csproj -- 2000 1
```

첫 인수는 1부터 시작할 seed 수(1~10,000), 둘째는 seed마다 진행할 연속 일수(1~30)입니다. 기본값은 2,000개 seed의 첫날, 12기업 총 24,000건입니다. 출력은 주석 줄을 포함한 CSV입니다.

새 시가는 실제 `Market.NextDay`에서 계산합니다. 구형 시가는 같은 사건·종가·난수로 구형 공식만 별도 계산하므로 가격 반응 규칙의 효과를 비교합니다. 여러 날을 지정해도 구형 가격 경로를 따로 누적하지 않습니다. 기업별 방향 일치율의 분모는 해당 기업의 모든 표본이며 보합은 일치로 세지 않습니다.

등급 표본은 실제 매일 판매하는 봉인 정보 9건입니다. `claim_truth_pct`는 취재 내용과 사건 사실의 일치율, `claim_price_pct`는 취재 내용이 암시하는 방향과 실제 개장 방향의 일치율입니다. 기업 추론의 성공률, 정보 비용·수수료 차감 후 수익률, 실제 플레이 성과는 측정하지 않습니다.

이 명령은 메모리 안에서 실행하며 사용자 저장이나 설정을 읽고 쓰지 않습니다. 공통 코어 검사에서는 별도로 128개 seed × 8일 × 12기업을 검증하고, 과거 자료 보존·가격 시나리오·후속 보도의 경계 조건도 확인합니다.
